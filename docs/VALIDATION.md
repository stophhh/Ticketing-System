# 검증 범위

## 자동 검증

통합 테스트 26개를 구성했습니다.

`./gradlew test`는 Spring Boot + MockMvc + H2를 사용하는 통합 테스트를 실행합니다.
회원·관리자 계정을 실제 저장하고 로그인 세션을 생성하여 API의 접근 권한과 상태 변경을 확인합니다.

- 인증 없는 요청, 회원의 관리자 기능 접근, CSRF 토큰 누락
- 실제 사용자 ID의 세션 저장, 잘못된 비밀번호, 로그아웃
- 회원가입의 관리자 역할 주입 차단, 비밀번호·IP 응답 제외
- 타인 예매 조회·취소·결제 차단
- 대기 중 자가 입장 차단, 타인 대기표 접근 차단, 중복 입장 요청 재사용
- 입장 허가와 만료 검증, 본인 선점 좌석만 예매
- 공연이 다른 좌석·중복 좌석·4매 초과 요청 차단
- 동시 선점·동시 예매에서 단일 성공
- 여러 좌석 선점 중 하나가 실패하면 전체 선점 롤백
- 서버 가격과 요청 금액 비교
- 중복 결제 요청·확정의 멱등성
- 취소·결제 중단·미결제 만료 시 좌석 반환
- 과거 취소 재요청이 새 예매의 좌석을 해제하지 않는지
- 관리자 좌석 수 입력 반영, 중복 생성 차단

## 범위의 한계

동시성 테스트는 같은 프로세스의 두 요청과 H2 데이터베이스로 확인합니다.
MySQL의 잠금·격리 수준, 다중 인스턴스 환경, 부하 처리량을 검증한 결과가 아닙니다.
실제 PG 승인·환불, 외부 결제 Webhook 검증도 구현하지 않았습니다.
기존 데이터베이스의 마이그레이션은 [별도 안내](MIGRATION.md)를 따라 확인해야 합니다.
